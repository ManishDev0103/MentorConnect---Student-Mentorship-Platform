Basic Steps to Run this project----------
	
		Frontend --->Backend --->Payment Services


Step 1. Check Software Requirements

	java -version
	mvnw -version
	node -v  (checks node version)
	npm -v		(checks node package manager version)

*****************************************************************************************************

Step 2. Database
		
	Check application.properties -----

						Path : MentorConnect/server/MentoshipBackend/(src/main/resources)/application.properties
	
	spring.datasource.url=jdbc:mysql://localhost:3306/mentorship?createDatabaseIfNotExist=true

	spring.datasource.username=root

	spring.datasource.password=yourPassword
